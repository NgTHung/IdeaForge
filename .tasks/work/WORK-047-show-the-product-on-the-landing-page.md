## Summary

Turn the landing page from two entry forms into a page that shows what IdeaForge does. Guests see an illustrated merge, a single Create board action, a compact join field, and the collect, organize, merge, conclude flow. Access policy and the sign-in requirement for creating boards stay unchanged.

## Acceptance Criteria

- [ ] The hero shows an illustrated merge of idea cards into a merged idea with ancestry links, labeled as an illustration, and respects reduced motion.
- [ ] Create board is the single primary action; joining by link or ID is a compact secondary field with the existing validation.
- [ ] A subheadline and a four-step section describe collecting, organizing, merging with originals kept, and concluding, using the app's vocabulary.
- [ ] The page uses a loaded typeface and the board dot grid, and fits a 390px viewport without horizontal overflow.
- [ ] Lint, typecheck, and production build pass; browser evidence and unverified paths are recorded.
